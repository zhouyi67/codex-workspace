## 二、 核心解决的五大行业实测痛点

1. **【防推拿发软】黄金打戏颗粒度法则**：坚持 2~3 秒整秒细切，严格执行“一镜一动一反馈”，杜绝单区间动作超载；
2. **【防相持僵化】动词属性铁律**：严禁长时状态动词（双手横架死封、持续对撞定格），全面采用瞬发瞬收动词，打斗高速连贯；
3. **【防单向挨揍】双向攻防与力量互换铁律**：对手必须具备正向致命输出，强制 3 轮攻守轮换与模式 K 互殴，拒绝沙包化；
4. **【防爆心瞬移 & 彻底防贴脸堆叠】四大终结收束空间协议**：
   * 协议 A（遗物残兵定场）、协议 B（物理抛飞两百米隔离）、协议 C（写意光粒解构湮灭）；
   * **协议 D（战意永动 · 纯打斗硬收尾）**：采用【反向错车背向飞出画框】或【单人刀光冲镜硬切】，彻底杜绝两人最后脸贴脸架刀堆叠！
5. **【防主客倒挂 & 绝杀草率】主角反杀大招三段式与视觉反超法则**：主角反击必须留足 4~5 秒，写清“破除束缚与光核压缩前摇 + 巨型立体开天巨刃物理厚度 + 沿途切碎反派大招造物”，解决主角反杀轻飘单薄、被反派特效抢戏的问题；
6. **【防降智污染】Seedance 2.5 官方实战标准**：原生单段最高支持 30 秒，使用整数秒时间戳，严禁毫秒时码，彻底清洗元指令与代码符号。
